# LexVault Pro - Gestor Documental Legal (Prototipo DevOps)

Este repositorio contiene el prototipo funcional web para el sistema de control de versiones de documentos legales.

El proyecto está empaquetado utilizando **Docker** para garantizar un entorno de ejecución estandarizado y local, aplicando los principios fundamentales de la metodología DevOps e integración continua, asegurando que se ejecute sin problemas de compatibilidad.

## Instrucciones Básicas de Instalación

Para ejecutar este prototipo en su máquina local, asegúrese de tener instalado [Docker Desktop](https://www.docker.com/products/docker-desktop).

### Paso 1: Clonar el repositorio
Descargue el código fuente en su equipo ejecutando en su terminal:
```bash
git clone <https://github.com/Daan-oozz/LegalDoc-Prototipo-DevOps>
cd LegalDoc-Prototipo-DevOps
